# 가이드 주제 백로그

주간 자동 발행 루틴이 **맨 위의 `- [ ]` 항목부터 하나씩** 가져다 씁니다.

## 규칙

- 글을 발행하면 그 항목을 `- [x]` 로 바꾸고 뒤에 `→ <slug>` 를 적습니다.
- 순서를 바꾸고 싶으면 줄을 위로 옮기면 됩니다. 맨 위가 다음 주에 나갑니다.
- 쓰고 싶은 주제가 생기면 원하는 위치에 `- [ ]` 줄을 추가하세요.
- `분류` 는 `content/guides/WRITING-GUIDE.md` 의 목록에 있는 것만 씁니다.
- 남은 항목이 5개 아래로 떨어지면 루틴이 커밋 메시지에 경고를 남깁니다.

형식: `- [ ] 제목 초안 — 분류: <분류> — 메모`
